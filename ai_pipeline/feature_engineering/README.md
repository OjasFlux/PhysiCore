# Feature Engineering

## Objective

Extract meaningful numerical features from sensor signals.

---

## Features

### Piezo

- Mean
- Maximum
- Minimum
- RMS
- Energy
- Variance

### MPU6050

- Mean
- Standard Deviation
- RMS
- Peak Acceleration
- Peak Angular Velocity

### Microphone

- RMS
- Peak Amplitude
- Zero Crossing Rate
- Signal Energy

---

## Output

Feature vectors used for AI training.
