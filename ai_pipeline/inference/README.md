# Real-Time Inference

## Objective

Run the trained TinyML model on the Arduino UNO Q for live machine fault detection.

---

## Inputs

- Piezo Sensor
- MPU6050
- MAX9814 Microphone

---

## Outputs

- Normal
- Minor Fault
- Moderate Fault
- Severe Fault

---

## Purpose

Perform real-time machine condition monitoring using multimodal sensor data.
