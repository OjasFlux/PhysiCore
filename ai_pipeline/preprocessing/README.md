# Data Preprocessing

## Objective

Prepare raw sensor datasets for AI model training.

---

## Tasks

- Remove empty rows
- Remove corrupted recordings
- Handle missing values
- Verify timestamps
- Normalize filenames
- Synchronize sensor datasets

---

## Input

Raw CSV files

---

## Output

Clean datasets ready for feature extraction.

---

## Folder Contents

- Data cleaning scripts
- Dataset validation scripts
- CSV formatting tools
