# PhysiCore – Physical AI Applications

## Material Property Inference

### Objective
Identify the type of material using sound, vibration, and motion sensor data.

### Tasks
- Select materials for testing.
- Collect sensor data from each material.
- Label the collected samples.
- Train the AI model.
- Test material identification accuracy.

### Physical Assets
- Wood
- Steel
- Plastic
- Glass
- Brick
- Ceramic

### Deliverables
- Material dataset
- Trained AI model
- Material classification results

### Priority
**High**
