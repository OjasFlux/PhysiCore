# Problem Statement

## Background

Many embedded AI systems rely on cameras or expensive industrial sensors, making them unsuitable for low-cost edge devices.

## Problem

Develop an Edge AI system capable of understanding physical interactions using low-cost sensors running entirely on the Arduino UNO Q.

## Objectives

- Design a Physical AI platform
- Build a multimodal sensing system
- Process acoustic, vibration, and motion signals
- Deploy a TinyML model on the edge
- Perform real-time inference

## Expected Outcome

A lightweight Physical Intelligence platform capable of analyzing physical interactions without cloud processing.
