# Abstract

This paper explains how **TinyML** enables machine learning models to run on low-power embedded devices such as Arduino, ESP32, and STM32. It reviews TinyML tools, hardware platforms, software frameworks, applications, challenges, and future research directions.

---

# Research Objective

The objective of this research is to study TinyML technology and explain how machine learning can be deployed on small embedded devices with limited memory and processing power.

---

# Problem Statement

Traditional machine learning models require:

- High processing power
- Large memory
- Cloud or Internet connectivity

These requirements make them difficult to use on embedded systems.

TinyML solves this problem by allowing machine learning models to run directly on microcontrollers.

# Feature Extraction Techniques

The paper recommends lightweight feature extraction methods that are suitable for TinyML.

| Feature | Purpose |
|---------|---------|
| **FFT (Fast Fourier Transform)** | Identifies frequency components in sound and vibration signals. |
| **RMS (Root Mean Square)** | Measures the strength or intensity of a signal. |
| **Signal Energy** | Calculates the total energy present in a signal. |
| **Zero Crossing Rate (ZCR)** | Counts how many times the signal crosses the zero-amplitude line. |
| **Statistical Features** | Extracts values such as mean, variance, and standard deviation. |

# Advantages

- Low power consumption
- Fast processing
- Real-time execution
- Reduced cloud dependency
- Improved privacy
- Suitable for embedded systems

---

# Limitations

- Limited RAM and Flash memory
- Limited computational power
- Small model size
- Lower performance than high-end computers

---

# Why This Paper is Useful for PhysiCore

This paper is useful because it explains how TinyML can be implemented on embedded systems such as Arduino.

It also supports the use of lightweight feature extraction techniques like:

- FFT
- RMS
- Signal Energy
- Zero Crossing Rate (ZCR)

These techniques are suitable for processing sound, vibration, and motion signals in real-time, making them ideal for the PhysiCore project.

---

# Key Findings

- TinyML enables machine learning on microcontrollers.
- Lightweight feature extraction improves processing speed.
- TensorFlow Lite Micro is widely used for embedded AI.
- CNN is one of the most commonly used models in TinyML applications.
- Efficient feature extraction reduces memory usage and computational complexity.

---

# Conclusion

The paper concludes that TinyML is an effective solution for deploying machine learning models on embedded systems. Lightweight feature extraction methods such as **FFT**, **RMS**, **Signal Energy**, and **Zero Crossing Rate (ZCR)** improve model performance while keeping memory usage and processing time low.
