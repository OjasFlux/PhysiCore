# Piezo Sensor Test

## Objective

Verify that the piezo vibration sensor works correctly with the Arduino UNO Q.

## Hardware

- Arduino UNO Q
- Piezo Vibration Sensor

## Connections

| Piezo | UNO Q |
|--------|-------|
| S | A0 |
| + | 3.3V |
| - | GND |

## Test

The sensor values were monitored through the Serial Monitor.

## Result

✅ Sensor successfully detected vibrations.

The analog values increased whenever the sensor was tapped.

## Status

PASS
